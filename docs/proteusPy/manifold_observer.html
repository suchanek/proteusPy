proteusPy.manifold_observer

ManifoldObserver: An (N+1)-dimensional observer that sees into an N-dimensional manifold.

The Concept

A ~proteusPy.turtleND.TurtleND walking an N-dim manifold is a flatland creature — it can only discover neighbors by moving to them. If we take its N-dim frame, extend it by one orthonormal dimension, and embed the resulting (N+1)-dim turtle into a new space, we create an extrinsic observer that can see the manifold surface from above.

The extra dimension is the normal to the manifold at each point. From this vantage the observer can see:

  • Topology: the shape and connectivity of the surface
  • Curvature: how fast the tangent plane rotates from node to node
  • Boundaries: where the manifold thins or ends
  • Class regions: clusters, ridges, and valleys in the surface
  • Any point's location: project straight down to the surface — no search needed

Construction

  1. Take the subject's N-dim orthonormal frame at a node.
  2. Append a zero column, then add the (N+1)-th basis vector [0,…,0,1].
  3. Orthonormalize → valid (N+1)×(N+1) frame.
  4. The observer's (N+1)-th basis vector is perpendicular to the entire N-dim tangent space — it points "straight up" off the surface.
  5. Lift all training data to (N+1)-space by appending a normal-residual height coordinate. Points on the manifold sit at h≈0; points off it rise above the surface.

The observer can then see the entire manifold as a relief map, and locate any query point by geometric projection rather than graph search.

 98

100    an observer that operates in (N+1)-dimensional space.  The extra

120    ManifoldModel(...)

122    >>> obs.ndim
123    6
124    >>> field = obs.observe()
125    >>> len(field) == 80

179    def _lift_point(self, point: np.ndarray, geom: NodeGeometry) -> np.ndarray:
180        """Lift an N-dim point to (N+1)-dim using local tangent geometry.
181
182        The (N+1)-th coordinate is the reconstruction error — how far
183        the point lies from the local tangent plane.  Points exactly on
184        the manifold have h=0; points off it have h>0.
185
186        Parameters
187        ----------
188        point : np.ndarray
189            Point in N-space, shape (N,).
190        geom : NodeGeometry
191            Local geometry (tangent basis + centroid) to measure against.
192
193        Returns
194        -------
195        np.ndarray
196            Lifted point in (N+1)-space, shape (N+1,).
197        """
198        diff = point - geom.centroid
199        d = geom.intrinsic_dim
200        projection = geom.basis[:d] @ diff  # project onto tangent (d,)
201        reconstructed = geom.basis[:d].T @ projection  # back to N-space (N,)
202        residual = diff - reconstructed
203        height = float(np.linalg.norm(residual))
204
205        lifted = np.zeros(self._ndim, dtype="d")
206        lifted[: len(point)] = point
207        lifted[-1] = height
208        return lifted
209
210    def lift_data(self) -> np.ndarray:
211        """Lift all training data to (N+1)-space.
212
213        Each point is lifted using the geometry of its nearest graph node.
214        The (N+1)-th coordinate encodes reconstruction error (distance
215        from the tangent plane).
216
217        Returns
218        -------
219        np.ndarray
220            Lifted data, shape (n_samples, N+1).
221        """
222        X = self._subject._X_train
223        n = len(X)
224        lifted = np.zeros((n, self._ndim), dtype="d")
225
226        for i in range(n):
227            node_id = f"n{i}"
228            geom = self._subject.get_geometry(node_id)
229            lifted[i] = self._lift_point(X[i], geom)
230
231        self._lifted_data = lifted
232        return lifted

236    def _compute_curvature(self, node_id: str) -> tuple[float, float]:
237        """Estimate curvature at a node from tangent-basis variation.
238
239        Curvature is the rate at which the tangent plane rotates as we
240        move along the surface.  Measured as the mean principal-angle
241        between this node's tangent basis and its neighbors'.
242
243        Returns
244        -------
245        tuple of (curvature, tangent_spread)
246        """
247        geom = self._subject.get_geometry(node_id)
248        neighbors = self._subject.get_neighbors(node_id)
249
250        if not neighbors:
251            return 0.0, 0.0
252
253        basis_src = geom.basis[: geom.intrinsic_dim]  # (d, N)
254        angles = []
255
256        for nbr_id, weight in neighbors:
257            nbr_geom = self._subject.get_geometry(nbr_id)
258            basis_tgt = nbr_geom.basis[: nbr_geom.intrinsic_dim]
259
260            # Principal angles between the two tangent subspaces via SVD
261            # of the cross-Gramian B_src @ B_tgt^T
262            # Use errstate to silence Apple Accelerate FPU exceptions on subnormal
263            # float32 patterns; sanitise result for degenerate tangent bases.
264            d_min = min(basis_src.shape[0], basis_tgt.shape[0])
265            b_src64 = np.nan_to_num(basis_src.astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0)
266            b_tgt64 = np.nan_to_num(basis_tgt.astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0)
267            with np.errstate(divide="ignore", invalid="ignore", over="ignore"):
268                cross = b_src64 @ b_tgt64.T  # (d_src, d_tgt)
269            cross = np.nan_to_num(cross, nan=0.0, posinf=0.0, neginf=0.0)
270            svs = np.linalg.svd(cross, compute_uv=False)
271            # Singular values are cosines of principal angles
272            svs = np.clip(svs[:d_min], -1.0, 1.0)
273            principal_angles = np.arccos(svs)
274            angles.append(float(np.mean(principal_angles)))
275
276        curvature = float(np.mean(angles)) if angles else 0.0
277        tangent_spread = float(np.std(angles)) if len(angles) > 1 else 0.0
278        return curvature, tangent_spread

280    def observe(self) -> list[ObservedGeometry]:
281        """Observe the entire manifold from above.
282
283        Lifts all data, computes curvature at every node, and builds
284        the complete observation field.  This is the core operation:
285        the observer *sees* the manifold in a single pass rather than
286        searching node by node.
287
288        Returns
289        -------
290        list of ObservedGeometry
291            One entry per graph node, containing the lifted position,
292            normal vector, curvature, and height.
293        """
294        # Step 1: Lift all data
295        self.lift_data()
296
297        X = self._subject._X_train
298        n = len(X)
299        curvatures = np.zeros(n, dtype="d")
300        observations: list[ObservedGeometry] = []
301
302        for i in range(n):
303            node_id = f"n{i}"
304            geom = self._subject.get_geometry(node_id)
305
306            # Curvature from tangent-basis variation
307            curvature, tangent_spread = self._compute_curvature(node_id)
308            curvatures[i] = curvature
309
310            # Normal vector in (N+1)-space: the last basis vector of the
311            # observer's extended frame
312            normal = np.zeros(self._ndim, dtype="d")
313            normal[-1] = 1.0  # points "up" off the manifold
314
315            obs = ObservedGeometry(
316                node_id=node_id,
317                position_lifted=self._lifted_data[i].copy(),
318                normal=normal,
319                curvature=curvature,
320                tangent_spread=tangent_spread,
321                height=float(self._lifted_data[i, -1]),
322                intrinsic_dim=geom.intrinsic_dim,
323            )
324            observations.append(obs)
325            self._observed[node_id] = obs
326
327        self._curvature_field = curvatures
328        return observations

332    def locate(self, query: np.ndarray) -> dict:
333        """Locate a query point on the manifold by direct projection.
334
335        Instead of walking the graph (like the subject must), the
336        observer projects the query straight down onto the manifold
337        surface.  This is O(N) distance computation, not O(hops)
338        graph traversal.
339
340        Parameters
341        ----------
342        query : np.ndarray
343            Point in N-space, shape (N,).
344
345        Returns
346        -------
347        dict with keys:
348            nearest_node : str
349                Closest graph node ID.
350            distance : float
351                Euclidean distance to nearest node.
352            height : float
353                Reconstruction error (how far off the manifold).
354            curvature : float
355                Local curvature at the nearest node.
356            label : optional
357                Class label at the nearest node (if supervised).
358            tangent_projection : np.ndarray
359                Query projected into the local tangent space.
360        """
361        query = np.asarray(query, dtype="d")
362        X = self._subject._X_train
363
364        # Direct geometric lookup — no graph walking
365        dists = np.linalg.norm(X - query, axis=1)
366        nearest_idx = int(np.argmin(dists))
367        nearest_id = f"n{nearest_idx}"
368        nearest_dist = float(dists[nearest_idx])
369
370        geom = self._subject.get_geometry(nearest_id)
371
372        # Compute height (reconstruction error from tangent plane)
373        diff = np.nan_to_num(
374            (query - geom.centroid).astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0
375        )
376        d = geom.intrinsic_dim
377        basis_d = np.nan_to_num(geom.basis[:d].astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0)
378        with np.errstate(divide="ignore", invalid="ignore", over="ignore"):
379            tangent_proj = basis_d @ diff  # (d,)
380            reconstructed = basis_d.T @ tangent_proj
381        tangent_proj = np.nan_to_num(tangent_proj, nan=0.0, posinf=0.0, neginf=0.0)
382        reconstructed = np.nan_to_num(reconstructed, nan=0.0, posinf=0.0, neginf=0.0)
383        residual = diff - reconstructed
384        height = float(np.linalg.norm(residual))
385
386        # Curvature from cached observation
387        curvature = 0.0
388        if nearest_id in self._observed:
389            curvature = self._observed[nearest_id].curvature
390
391        label = None
392        if self._subject._y_train is not None:
393            label = self._subject._y_train[nearest_idx]
394
395        return {
396            "nearest_node": nearest_id,
397            "distance": nearest_dist,
398            "height": height,
399            "curvature": curvature,
400            "label": label,
401            "tangent_projection": tangent_proj,
402        }

420    def predict(self, X: np.ndarray) -> np.ndarray:
421        """Classify by observation — no graph walking needed.
422
423        The observer projects each query straight down to the manifold
424        surface and reads the label at the landing point.  This is a
425        direct geometric computation, not a search.
426
427        Parameters
428        ----------
429        X : np.ndarray
430            Query points, shape (n, N).
431
432        Returns
433        -------
434        np.ndarray
435            Predicted labels.
436        """
437        if self._subject._y_train is None:
438            raise RuntimeError("Subject model has no labels")
439
440        X = np.asarray(X, dtype="d")
441        predictions = np.empty(len(X), dtype=self._subject._y_train.dtype)
442
443        for i, query in enumerate(X):
444            result = self.locate(query)
445            predictions[i] = result["label"]

447        return predictions

451    def sync(self, node_id: str | None = None) -> None:
452        """Synchronize the observer's frame with the subject's manifold.
453
454        Extends the subject's N-dim frame at the given node (or the
455        subject's current node) to an (N+1)-dim observer frame where
456        the extra basis vector is the manifold normal.
457
458        Parameters
459        ----------
460        node_id : str, optional
461            Node to sync at.  If None, uses the subject's current node.
462        """
463        if node_id is None:
464            node_id = self._subject.current_node
465        if node_id is None:
466            raise RuntimeError("No node to sync at — fly the subject first or specify node_id")
467
468        N = self._subject.ndim
469        geom = self._subject.get_geometry(node_id)
470        emb = self._subject.graph.get_embedding(node_id)
471
472        # Build the subject's full N×N frame (padded if truncated)
473        subject_frame = self._subject._pad_basis(geom.basis)  # (N, N)
474
475        # Extend to (N+1) × (N+1): pad each row with 0, add normal row
476        frame_ext = np.zeros((self._ndim, self._ndim), dtype="d")
477        frame_ext[:N, :N] = subject_frame
478        frame_ext[N, N] = 1.0  # the normal — perpendicular to all of R^N
479
480        # Position in (N+1)-space: subject position + altitude along normal
481        pos_ext = np.zeros(self._ndim, dtype="d")
482        pos_ext[:N] = emb
483        pos_ext[N] = self._altitude
484
485        self._observer._position = pos_ext
486        self._observer._frame = frame_ext
487        self._observer.orthonormalize()

489    def lift_off(self, height: float) -> None:
490        """Rise above (or descend toward) the manifold surface.
491
492        Parameters
493        ----------
494        height : float
495            Distance to move in the normal direction.
496            Positive = rise above, negative = descend.
497        """
498        self._altitude += height
499        # Move observer along its last basis vector (the normal)
500        self._observer._position[-1] = self._altitude

506        the observer.

515    def pan(self, direction: np.ndarray, distance: float) -> None:
516        """Move the observer laterally (parallel to the manifold surface).
517
518        Parameters
519        ----------
520        direction : np.ndarray
521            Direction in N-space to pan, shape (N,).
522        distance : float
523            Distance to move.
524        """
525        direction = np.asarray(direction, dtype="d")
526        norm = np.linalg.norm(direction)
527        if norm < 1e-10:
528            return
529        direction = direction / norm
530
531        # Move in (N+1)-space but only in the first N components
532        move_vec = np.zeros(self._ndim, dtype="d")
533        move_vec[: self._subject.ndim] = direction * distance
534        self._observer._position += move_vec

589    def topology_summary(self) -> dict:
590        """Summarize what the observer sees about the manifold.
591
592        Returns
593        -------
594        dict with keys:
595            n_nodes, ambient_dim, observer_dim, mean_curvature,
596            max_curvature, mean_height, max_height,
597            mean_intrinsic_dim, curvature_std, high_curvature_nodes
598        """
599        if not self._observed:
600            self.observe()
601
602        curvatures = [o.curvature for o in self._observed.values()]
603        heights = [o.height for o in self._observed.values()]
604        dims = [o.intrinsic_dim for o in self._observed.values()]
605
606        mean_curv = float(np.mean(curvatures))
607        std_curv = float(np.std(curvatures))
608        threshold = mean_curv + 2.0 * std_curv
609
610        high_curv_nodes = [o.node_id for o in self._observed.values() if o.curvature > threshold]
611
612        return {
613            "n_nodes": len(self._observed),
614            "ambient_dim": self._subject.ndim,
615            "observer_dim": self._ndim,
616            "mean_curvature": mean_curv,
617            "max_curvature": float(np.max(curvatures)) if curvatures else 0.0,
618            "curvature_std": std_curv,
619            "mean_height": float(np.mean(heights)) if heights else 0.0,
620            "max_height": float(np.max(heights)) if heights else 0.0,

627    def observe_path(
628        self,
629        path: list[str],
630        pen_down: bool = True,
631    ) -> dict:
632        """See a walker's traced path from the observer's vantage above the surface.
633
634        The classical turtle can drop a pen and draw on the plane.  In the
635        manifold the walker traces a sequence of N-dim positions.  The observer,
636        sitting one dimension higher, sees the complete trajectory as a relief
637        curve: each hop is lifted to (N+1)-space, with the extra coordinate
638        encoding height above the local tangent plane.
639
640        This is the "pen-down" view: what Flatland's Sphere sees looking down
641        at the curve the Flatlander drew while walking.
642
643        Parameters
644        ----------
645        path : list of str
646            Ordered list of node IDs visited by the walker (e.g.
647            ``ManifoldModel.flight_path``).
648        pen_down : bool
649            If True (default), compute and return the full lifted trajectory.
650            If False, returns only the per-hop metadata without lifting.
651
652        Returns
653        -------
654        dict with keys:
655
656        ``positions_N`` : np.ndarray, shape (n_hops, N)
657            Walker positions in N-space (original manifold coordinates).
658        ``positions_lifted`` : np.ndarray, shape (n_hops, N+1)
659            Walker positions in (N+1)-space as seen by the observer.
660            The last column is the reconstruction-error height at each hop.
661        ``heights`` : np.ndarray, shape (n_hops,)
662            Observer height coordinate at each hop (= reconstruction error
663            from the local tangent plane).  Zero = on the manifold; positive =
664            off the manifold surface (noise / curvature gap).
665        ``curvatures`` : np.ndarray, shape (n_hops,)
666            Curvature at each hop node (mean principal angle to neighbors).
667        ``intrinsic_dims`` : np.ndarray of int, shape (n_hops,)
668            Local intrinsic dimensionality at each hop.
669        ``class_labels`` : list
670            Class label at each hop node (None if model is unsupervised).
671        ``path`` : list of str
672            Input path, echoed back.
673        ``n_hops`` : int
674            Number of hops.
675        ``boundary_crossings`` : list of int
676            Hop indices where the class label changes.
677
678        Examples
679        --------
680        >>> import numpy as np
681        >>> from proteusPy.manifold_model import ManifoldModel
682        >>> from proteusPy.manifold_observer import ManifoldObserver
683        >>> rng = np.random.default_rng(0)
684        >>> X = rng.standard_normal((60, 4))
685        >>> y = (X[:, 0] > 0).astype(int)
686        >>> model = ManifoldModel(k_graph=6, k_pca=15)
687        >>> _ = model.fit(X, y)
688        >>> _ = model.fly_to("n0")
689        >>> path = model.fly_toward(X[30], max_steps=10)
690        >>> obs = ManifoldObserver(model)
691        >>> result = obs.observe_path(path)
692        >>> result["n_hops"] == len(path)
693        True
694        >>> result["positions_lifted"].shape[1] == 5  # N+1 = 4+1
695        True
696        """
697        if not path:
698            return {
699                "positions_N": np.empty((0, self._subject.ndim)),
700                "positions_lifted": np.empty((0, self._ndim)),
701                "heights": np.array([]),
702                "curvatures": np.array([]),
703                "intrinsic_dims": np.array([], dtype=int),
704                "class_labels": [],
705                "path": path,
706                "n_hops": 0,
707                "boundary_crossings": [],
708            }
709
710        N = self._subject.ndim
711        n_hops = len(path)
712        pos_N = np.zeros((n_hops, N), dtype="d")
713        pos_lifted = np.zeros((n_hops, self._ndim), dtype="d")
714        heights = np.zeros(n_hops, dtype="d")
715        curvatures = np.zeros(n_hops, dtype="d")
716        intrinsic_dims = np.zeros(n_hops, dtype=int)
717        labels: list = []
718
719        for i, node_id in enumerate(path):
720            # Raw position in N-space
721            emb = self._subject.graph.get_embedding(node_id)
722            pos_N[i] = emb
723
724            # Geometry at this node
725            geom = self._subject.get_geometry(node_id)
726            intrinsic_dims[i] = geom.intrinsic_dim
727
728            # Curvature — use cached value if observe() was called, else compute
729            if node_id in self._observed:
730                curv = self._observed[node_id].curvature
731            else:
732                curv, _ = self._compute_curvature(node_id)
733            curvatures[i] = curv
734
735            # Lift to (N+1)-space
736            if pen_down:
737                lifted = self._lift_point(emb, geom)
738            else:
739                lifted = np.zeros(self._ndim, dtype="d")
740                lifted[:N] = emb
741            pos_lifted[i] = lifted
742            heights[i] = float(lifted[-1])
743
744            # Class label
745            idx = int(node_id[1:])
746            if self._subject._y_train is not None and idx < len(self._subject._y_train):
747                labels.append(self._subject._y_train[idx])
748            else:
749                labels.append(None)
750
751        # Boundary crossings — hops where class changes
752        crossings = []
753        for i in range(1, n_hops):
754            if labels[i] is not None and labels[i - 1] is not None:
755                if labels[i] != labels[i - 1]:
756                    crossings.append(i)
757
758        return {
759            "positions_N": pos_N,
760            "positions_lifted": pos_lifted,
761            "heights": heights,
762            "curvatures": curvatures,
763            "intrinsic_dims": intrinsic_dims,
764            "class_labels": labels,
765            "path": path,
766            "n_hops": n_hops,
767            "boundary_crossings": crossings,
768        }

180    def _lift_point(self, point: np.ndarray, geom: NodeGeometry) -> np.ndarray:
181        """Lift an N-dim point to (N+1)-dim using local tangent geometry.
182
183        The (N+1)-th coordinate is the reconstruction error — how far
184        the point lies from the local tangent plane.  Points exactly on
185        the manifold have h=0; points off it have h>0.
186
187        Parameters
188        ----------
189        point : np.ndarray
190            Point in N-space, shape (N,).
191        geom : NodeGeometry
192            Local geometry (tangent basis + centroid) to measure against.
193
194        Returns
195        -------
196        np.ndarray
197            Lifted point in (N+1)-space, shape (N+1,).
198        """
199        diff = point - geom.centroid
200        d = geom.intrinsic_dim
201        projection = geom.basis[:d] @ diff  # project onto tangent (d,)
202        reconstructed = geom.basis[:d].T @ projection  # back to N-space (N,)
203        residual = diff - reconstructed
204        height = float(np.linalg.norm(residual))
205
206        lifted = np.zeros(self._ndim, dtype="d")
207        lifted[: len(point)] = point
208        lifted[-1] = height
209        return lifted

237    def _compute_curvature(self, node_id: str) -> tuple[float, float]:
238        """Estimate curvature at a node from tangent-basis variation.
239
240        Curvature is the rate at which the tangent plane rotates as we
241        move along the surface.  Measured as the mean principal-angle
242        between this node's tangent basis and its neighbors'.
243
244        Returns
245        -------
246        tuple of (curvature, tangent_spread)
247        """
248        geom = self._subject.get_geometry(node_id)
249        neighbors = self._subject.get_neighbors(node_id)
250
251        if not neighbors:
252            return 0.0, 0.0
253
254        basis_src = geom.basis[: geom.intrinsic_dim]  # (d, N)
255        angles = []
256
257        for nbr_id, weight in neighbors:
258            nbr_geom = self._subject.get_geometry(nbr_id)
259            basis_tgt = nbr_geom.basis[: nbr_geom.intrinsic_dim]
260
261            # Principal angles between the two tangent subspaces via SVD
262            # of the cross-Gramian B_src @ B_tgt^T
263            # Use errstate to silence Apple Accelerate FPU exceptions on subnormal
264            # float32 patterns; sanitise result for degenerate tangent bases.
265            d_min = min(basis_src.shape[0], basis_tgt.shape[0])
266            b_src64 = np.nan_to_num(basis_src.astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0)
267            b_tgt64 = np.nan_to_num(basis_tgt.astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0)
268            with np.errstate(divide="ignore", invalid="ignore", over="ignore"):
269                cross = b_src64 @ b_tgt64.T  # (d_src, d_tgt)
270            cross = np.nan_to_num(cross, nan=0.0, posinf=0.0, neginf=0.0)
271            svs = np.linalg.svd(cross, compute_uv=False)
272            # Singular values are cosines of principal angles
273            svs = np.clip(svs[:d_min], -1.0, 1.0)
274            principal_angles = np.arccos(svs)
275            angles.append(float(np.mean(principal_angles)))
276
277        curvature = float(np.mean(angles)) if angles else 0.0
278        tangent_spread = float(np.std(angles)) if len(angles) > 1 else 0.0
279        return curvature, tangent_spread

333    def locate(self, query: np.ndarray) -> dict:
334        """Locate a query point on the manifold by direct projection.
335
336        Instead of walking the graph (like the subject must), the
337        observer projects the query straight down onto the manifold
338        surface.  This is O(N) distance computation, not O(hops)
339        graph traversal.
340
341        Parameters
342        ----------
343        query : np.ndarray
344            Point in N-space, shape (N,).
345
346        Returns
347        -------
348        dict with keys:
349            nearest_node : str
350                Closest graph node ID.
351            distance : float
352                Euclidean distance to nearest node.
353            height : float
354                Reconstruction error (how far off the manifold).
355            curvature : float
356                Local curvature at the nearest node.
357            label : optional
358                Class label at the nearest node (if supervised).
359            tangent_projection : np.ndarray
360                Query projected into the local tangent space.
361        """
362        query = np.asarray(query, dtype="d")
363        X = self._subject._X_train
364
365        # Direct geometric lookup — no graph walking
366        dists = np.linalg.norm(X - query, axis=1)
367        nearest_idx = int(np.argmin(dists))
368        nearest_id = f"n{nearest_idx}"
369        nearest_dist = float(dists[nearest_idx])
370
371        geom = self._subject.get_geometry(nearest_id)
372
373        # Compute height (reconstruction error from tangent plane)
374        diff = np.nan_to_num(
375            (query - geom.centroid).astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0
376        )
377        d = geom.intrinsic_dim
378        basis_d = np.nan_to_num(geom.basis[:d].astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0)
379        with np.errstate(divide="ignore", invalid="ignore", over="ignore"):
380            tangent_proj = basis_d @ diff  # (d,)
381            reconstructed = basis_d.T @ tangent_proj
382        tangent_proj = np.nan_to_num(tangent_proj, nan=0.0, posinf=0.0, neginf=0.0)
383        reconstructed = np.nan_to_num(reconstructed, nan=0.0, posinf=0.0, neginf=0.0)
384        residual = diff - reconstructed
385        height = float(np.linalg.norm(residual))
386
387        # Curvature from cached observation
388        curvature = 0.0
389        if nearest_id in self._observed:
390            curvature = self._observed[nearest_id].curvature
391
392        label = None
393        if self._subject._y_train is not None:
394            label = self._subject._y_train[nearest_idx]
395
396        return {
397            "nearest_node": nearest_id,
398            "distance": nearest_dist,
399            "height": height,
400            "curvature": curvature,
401            "label": label,
402            "tangent_projection": tangent_proj,
403        }

453        """Synchronize the observer's frame with the subject's manifold.
454
455        Extends the subject's N-dim frame at the given node (or the
456        subject's current node) to an (N+1)-dim observer frame where
457        the extra basis vector is the manifold normal.

462            Node to sync at.  If None, uses the subject's current node.

465            node_id = self._subject.current_node
466        if node_id is None:
467            raise RuntimeError("No node to sync at — fly the subject first or specify node_id")

516    def pan(self, direction: np.ndarray, distance: float) -> None:
517        """Move the observer laterally (parallel to the manifold surface).
518
519        Parameters
520        ----------
521        direction : np.ndarray
522            Direction in N-space to pan, shape (N,).
523        distance : float
524            Distance to move.
525        """
526        direction = np.asarray(direction, dtype="d")
527        norm = np.linalg.norm(direction)
528        if norm < 1e-10:
529            return
530        direction = direction / norm
531
532        # Move in (N+1)-space but only in the first N components

656

658            Walker positions in N-space (original manifold coordinates).
659        ``positions_lifted`` : np.ndarray, shape (n_hops, N+1)
660            Walker positions in (N+1)-space as seen by the observer.
661            The last column is the reconstruction-error height at each hop.
662        ``heights`` : np.ndarray, shape (n_hops,)

668        ``intrinsic_dims`` : np.ndarray of int, shape (n_hops,)

683        >>> from proteusPy.manifold_observer import ManifoldObserver

686        >>> y = (X[:, 0] > 0).astype(int)

698        if not path:
699            return {

712        n_hops = len(path)
713        pos_N = np.zeros((n_hops, N), dtype="d")
714        pos_lifted = np.zeros((n_hops, self._ndim), dtype="d")
715        heights = np.zeros(n_hops, dtype="d")
716        curvatures = np.zeros(n_hops, dtype="d")
717        intrinsic_dims = np.zeros(n_hops, dtype=int)
718        labels: list = []
719
720        for i, node_id in enumerate(path):
721            # Raw position in N-space
722            emb = self._subject.graph.get_embedding(node_id)
723            pos_N[i] = emb
724

727            intrinsic_dims[i] = geom.intrinsic_dim
728

743            heights[i] = float(lifted[-1])

747            if self._subject._y_train is not None and idx < len(self._subject._y_train):

749            else:
750                labels.append(None)
751
752        # Boundary crossings — hops where class changes
753        crossings = []

756                if labels[i] != labels[i - 1]:
757                    crossings.append(i)

334        """Locate a query point on the manifold by direct projection.
335
336        Instead of walking the graph (like the subject must), the
337        observer projects the query straight down onto the manifold
338        surface.  This is O(N) distance computation, not O(hops)
339        graph traversal.
340
341        Parameters
342        ----------
343        query : np.ndarray
344            Point in N-space, shape (N,).
345
346        Returns
347        -------
348        dict with keys:
349            nearest_node : str
350                Closest graph node ID.
351            distance : float
352                Euclidean distance to nearest node.
353            height : float
354                Reconstruction error (how far off the manifold).
355            curvature : float
356                Local curvature at the nearest node.
357            label : optional
358                Class label at the nearest node (if supervised).
359            tangent_projection : np.ndarray
360                Query projected into the local tangent space.
361        """
362        query = np.asarray(query, dtype="d")
363        X = self._subject._X_train
364
365        # Direct geometric lookup — no graph walking
366        dists = np.linalg.norm(X - query, axis=1)
367        nearest_idx = int(np.argmin(dists))

370
371        geom = self._subject.get_geometry(nearest_id)
372
373        # Compute height (reconstruction error from tangent plane)
374        diff = np.nan_to_num(
375            (query - geom.centroid).astype(np.float64), nan=0.0, posinf=0.0, neginf=0.0
376        )

379        with np.errstate(divide="ignore", invalid="ignore", over="ignore"):
380            tangent_proj = basis_d @ diff  # (d,)
381            reconstructed = basis_d.T @ tangent_proj
382        tangent_proj = np.nan_to_num(tangent_proj, nan=0.0, posinf=0.0, neginf=0.0)
